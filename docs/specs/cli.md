# コマンドライン

<!-- @code src/main.rs#parse_args -->

## 使い方

```sh
miyaburu [オプション] <Markdownファイル>
```

Markdownファイルを1つ受け取り、HTMLを生成します。\
既定ではブラウザーを開きません。\
ブラウザーの終了は待たずに終了するので、呼び出したエージェントやシェルを止めません。
生成したローカルHTMLのパスは標準出力に1行で表示します。
ローカル生成後、HTMLパスを標準出力に表示してflushし、`--open` 指定時は共有開始前にブラウザーで開いてからCloudflare Quick Tunnelで共有を試みます。\
ブラウザーの起動に失敗すると終了コード1で終了し、新しい共有は起動しません。\
共有用のHTMLは、ローカル生成と同じ原文・設定を使います。
共有URL、余白（quiet zone）付きQRコード、停止方法、共有失敗の説明は標準エラーに表示します。
QRコードの生成だけに失敗した場合は理由を標準エラーに表示し、共有URLの表示は維持します。
共有にはPATH上の `cloudflared` が必要です。未導入、異常終了、15秒以内にURLを取得できない場合などは共有を片付け、ローカル表示へ戻ります。
共有の失敗だけでは終了コード1にしません。
共有はコマンド終了後も続き、同じ文書のcanonical絶対パスで再実行すると、生存する共有URLを再利用しHTMLと画像を一括更新します。
スマホは手動で再読み込みします。URLを知る人は閲覧でき、認証はありません。
詳しい管理・配信の契約は[共有](sharing.md)、画像とリンクの契約は[共有用の変換](shared-rendering.md)を参照してください。

| オプション | 動作 |
| --- | --- |
| `-c`、`--config <ファイル>` | [設定ファイル](configuration.md)を指定します。 |
| `-o`、`--output <ディレクトリ>` | HTMLの出力先を指定します。 |
| `--no-open` | ブラウザーだけを抑止します。共有は止めません。 |
| `--open` | ローカルHTMLをブラウザーで開きます。 |
| `--no-share` | 共有せず、従来のローカルHTML生成だけを行います。 |
| `--stop <Markdownファイル>` | 指定文書の共有を停止します。 |
| `--stop-all` | すべての共有を停止します。 |
| `-h`、`--help` | 使い方を表示します。 |
| `-V`、`--version` | バージョンを表示します。 |

`--no-open` は互換用です。\
`--open` と `--no-open` を両方指定した場合は、最後の指定が有効です。

値を取るオプションは、`--config 設定.toml` と `--config=設定.toml` のどちらでも書けます。
`--` より後ろは、`-` で始まっていてもファイル名として扱います。

## 共有の停止

`miyaburu --stop <Markdownファイル>` または `miyaburu --stop-all` で停止します。
停止済みも成功とし、標準出力には何も出さず、標準エラーに説明を出します。
停止オプションは通常生成の引数やほかのオプション（`--open`、`--no-open` を含む）と併用しません。
文書が消えた場合も、共有開始時と同じ絶対パスを指定して停止を試みられます。
存在する文書はcanonical絶対パスで照合します。
ファイルが存在しない場合は指定パスを絶対パスにし、親ディレクトリをcanonical化してファイル名を結合します。
これにより、`/tmp` と `/private/tmp` やシンボリックリンクの親パスを経由した指定でも、削除前の文書と同じキーで停止を試みます。
親ディレクトリも消えている場合だけ、指定した絶対パスのままで照合します。
共有の状態・ログ・スナップショットは通常の利用者キャッシュで管理し、`--output` では変更しません。
内部の `--share-daemon` はバックグラウンド起動専用で、公開ヘルプには表示しません。

## 出力先

`--output` を指定しない場合は、利用者ごとのキャッシュ用ディレクトリに出力します。

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Caches/miyaburu/<文書ごとの識別子>/` |
| そのほか | `$XDG_CACHE_HOME/miyaburu/<文書ごとの識別子>/`（未設定なら `~/.cache/miyaburu/…`） |

- 識別子はMarkdownファイルの絶対パスから決まります。同じ文書を開き直すと、同じ場所を上書きします。
- `index.html` を書き出します。Mermaidの図を含む文書では `mermaid.min.js` も書き出します。

`--output` の有無にかかわらず、次のように書き出します。

- 新しく作るディレクトリと、書き出すファイルは、本人だけが読める権限にします。
  すでにあるディレクトリの権限は変えません。
- 一時ファイルに書いてから置き換えます。
  出力先がシンボリックリンクでも、リンク先のファイルは書き換えません。
- 出力先が入力のMarkdownファイル自身になる場合は、書き出さずにエラーで終了します。

## ブラウザーの起動

- macOSでは `open`、そのほかのUnix系では `xdg-open` で開きます。
- 起動用のコマンドの終了を最長2秒待ち、失敗していれば終了コード1で終了します。
- 2秒以内に終わらない場合は、ブラウザーが前面で動いているとみなし、待たずに終了します。
- Windowsは対象にしていません。

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 成功。 |
| 1 | Markdownや設定を読めない、HTMLを書き出せない、ブラウザーを開けない、共有停止に失敗した。 |
| 2 | 引数の指定が正しくない。 |

失敗の理由は、対象のファイル名とともに標準エラーへ表示します。
