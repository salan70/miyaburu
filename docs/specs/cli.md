# コマンドライン

<!-- @code src/main.rs#parse_args -->

## 使い方

```sh
miyaburu [オプション] <Markdownファイル>
```

Markdownファイルを1つ受け取り、HTMLを生成して既定のブラウザーで開きます。
ブラウザーの終了は待たずに終了するので、呼び出したエージェントやシェルを止めません。
生成したHTMLのパスは標準出力に1行で表示します。

| オプション | 動作 |
| --- | --- |
| `-c`、`--config <ファイル>` | [設定ファイル](configuration.md)を指定します。 |
| `-o`、`--output <ディレクトリ>` | HTMLの出力先を指定します。 |
| `--no-open` | ブラウザーを開かず、HTMLの生成とパスの表示だけを行います。 |
| `-h`、`--help` | 使い方を表示します。 |
| `-V`、`--version` | バージョンを表示します。 |

値を取るオプションは、`--config 設定.toml` と `--config=設定.toml` のどちらでも書けます。
`--` より後ろは、`-` で始まっていてもファイル名として扱います。

## 出力先

`--output` を指定しない場合は、利用者ごとのキャッシュ用ディレクトリに出力します。

| OS | 場所 |
| --- | --- |
| macOS | `~/Library/Caches/miyaburu/<文書ごとの識別子>/` |
| そのほか | `$XDG_CACHE_HOME/miyaburu/<文書ごとの識別子>/`（未設定なら `~/.cache/miyaburu/…`） |

- 識別子はMarkdownファイルの絶対パスから決まります。同じ文書を開き直すと、同じ場所を上書きします。
- `index.html` を書き出します。Mermaidの図を含む文書では `mermaid.min.js` も書き出します。

`--output` の有無にかかわらず、次のように書き出します。

- 新しく作るディレクトリと、書き出すファイルは、本人だけが読める権限にします。
  すでにあるディレクトリの権限は変えません。
- 一時ファイルに書いてから置き換えます。
  出力先がシンボリックリンクでも、リンク先のファイルは書き換えません。
- 出力先が入力のMarkdownファイル自身になる場合は、書き出さずにエラーで終了します。

## ブラウザーの起動

- macOSでは `open`、そのほかのUnix系では `xdg-open` で開きます。
- 起動用のコマンドの終了を最長2秒待ち、失敗していれば終了コード1で終了します。
- 2秒以内に終わらない場合は、ブラウザーが前面で動いているとみなし、待たずに終了します。
- Windowsは対象にしていません。

## 終了コード

| 終了コード | 意味 |
| --- | --- |
| 0 | 成功。 |
| 1 | Markdownや設定を読めない、HTMLを書き出せない、ブラウザーを開けない。 |
| 2 | 引数の指定が正しくない。 |

失敗の理由は、対象のファイル名とともに標準エラーへ表示します。
